# Fact Drift Auto Remediation

本通道只处理低风险事实漂移。它不是普通问题自动修复授权，也不是改写需求、设计或验收标准的入口。

---

## `DOC-*` 模型

每个可自动修复的事实漂移使用固定字段：

| 字段 | 规则 |
| --- | --- |
| ID | 首次记录时依次分配 `DOC-001`、`DOC-002` |
| 类型 | `task-status`、`brief-stale`、`implementation-note`、`check-record`、`mechanical-link`、`fact-status`、`code-comment-fact` |
| 文件 | 需要修改的任务/项目文档、本地上下文摘要或源码注释路径 |
| 漂移 | 文字与实际 diff / 状态不一致的事实 |
| 证据 | `file:line`、命令输出或 diff 摘要 |
| 修复 | 要替换的精确事实片段 |
| 验证 | 静态检查或重读确认 |

`DOC-*` 不占用 `CHK-*` 或 `FBK-*` 编号。自动修复失败或越界时，根据根因转成 `CHK-*`、`FBK-*` 或剩余风险。

---

## 允许自动修复

满足以下全部条件才可自动修复：

- 目标是任务文档/记录、机械链接、本地摘要、项目文档事实片段，或符合专项规则的源码注释事实片段；
- 内容可由实际 diff、任务状态、命令输出或已读任务材料唯一推出；
- 不新增需求、不改变验收标准、不改变设计取舍、不替用户选择产品语义；
- 不修改可执行源码、配置、测试、迁移、生产数据或外部系统；源码注释只允许按专项规则替换事实片段；
- 可修复性由片段语义决定；只改证据唯一推出的状态、URL、版本、配置键、命令结果、验证结论或时间点；
- 不改操作步骤、责任边界、安全提示、协议字段或对外承诺，且可由重读或静态检查验证；
- 用户没有明确要求本轮绝对只读。

典型例子：

- `brief.md` 漏掉 diff 已证明的实现范围，或 `implement.md` 状态机械过期；
- 任务记录中的路径、命令、链接、深度、route 或状态与确定性证据不一致；
- 项目文档仍写旧状态、版本或地址，但发布记录、回读、测试或 diff 唯一证明已变化；
- 源码注释中的符号、路径、版本或局部实现事实已机械过期，且满足专项双重证据和排除规则。

发现源码注释事实候选时才读取 `references/code-comment-auto-remediation.md`；未发现候选时不得把该文件加入默认上下文。

---

## 禁止自动修复

以下情况不得自动改，必须根据根因进入 `CHK-*`、`FBK-*`、剩余风险或阻塞：

- PRD、Acceptance Criteria、业务规则、UI 文案或 design 取舍需要实质变更；
- 实现与规划冲突，无法判断是代码错还是文档错；
- 需要新增测试、修改可执行代码、改配置、改迁移或调用外部系统；
- 证据来自推测、聊天摘要或未读取的文件；
- 修复会改写操作路径、协议、权限/安全边界、上线承诺、责任或验收口径；
- 修改会扩大范围或影响发布、权限、数据安全、生产行为。

---

## 写入时机

1. 完成可继续的检查并收集 `CHK-*`、`FBK-*`、`DOC-*`。
2. 报告前应用白名单 DOC；重读最终 diff，重算范围和 `check_profile`，再运行无副作用验证。
3. “自动修复”区列出文件、修复和验证；范围摘要包含新 diff。

subagent 模式只返回 `DOC-*` 候选；主会话按同一规则决定是否写入。validated auto-loop 模式由主会话完成允许的 `DOC-*` 修复后再 `record`。

### Validated Auto-Loop 绑定

- 只有当前任务的 `implement.md` 与 `brief.md` 参与 runner DOC 重绑；每个实际修改文件使用一次 `--doc-remediation-file <repository>::<path>`。
- 声明集合必须与 Check action 发出后的真实变化完全一致。`prd.md`、`design.md`、其它任务或其它文件一律不允许借此重绑。
- `check.jsonl` 可按本通道记录，但它不属于 planning/handoff hash，不传 `--doc-remediation-file`。
- 源码注释改动不参与 runner DOC 重绑，也不得传 `--doc-remediation-file`；仍须纳入最终 diff、范围画像和定向验证。
- record 返回 `status=retryable reason=artifact-drift` 时不运行 `next`；先撤回误改、补齐合法 DOC 声明后重录，或在无法安全归因时显式回写 `blocked + artifact-drift`。

---

## 失败处理

- 无法唯一确定时转 `CHK-*`、`FBK-*` 或剩余风险。
- 验证失败时转 `CHK-*` / `FBK-*` 并报告证据；影响面扩大时停止自修。
